# Retired AFE-line Excel profile

The former `afe-lines-default` spreadsheet profile required catalogue items,
planned quantities, units, and daily-consumption inputs. It is no longer
registered in the active API because current AFE Lines are scope-only.

Use **AFE** to configure Primary/Secondary classification, cost code, type,
rate basis, and section; submit the AFE, then use **AFE Cost Estimates** to
enter its estimated rates. Actual consumable quantity and UOM belong to the
Daily Cost entry.
